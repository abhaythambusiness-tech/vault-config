# Sistema de Tags para el Vault

Convenciones recomendadas. Usar siempre estos tags en lugar de inventar variantes.

## Por área temática
- `#trading` — todo lo relacionado con mercados financieros
- `#python` — código Python, scripts, bots
- `#obsidian` — sobre el propio sistema de notas
- `#ia` — inteligencia artificial, modelos, prompts
- `#automatizacion` — n8n, workflows, scripts automáticos
- `#servidor` — Ubuntu server, Docker, SSH
- `#estudio` — notas de examen y aprendizaje
- `#proyecto` — proyectos activos

## Por asignatura (estudios)
- `#fol` — Formación y Orientación Laboral
- `#smr` — Sistemas Microinformáticos y Redes
- `#hardware` — componentes físicos
- `#redes` — redes informáticas

## Por tipo de contenido
- `#guia` — instrucciones paso a paso
- `#referencia` — información técnica permanente
- `#80-20` — resúmenes para examen con metodología Pareto
- `#plantilla` — notas que son plantillas para otras

## Por estado
- `#wip` — Work in Progress, nota incompleta
- `#revisar` — necesita revisión o actualización
- `#urgente` — alta prioridad

## Reglas
- Nunca usar espacios: `#trading-bot` no `#trading bot`
- Nunca duplicar con variantes: elegir UNO y usarlo siempre
- Máximo 5 tags por nota
- Los tags de área siempre van primero
