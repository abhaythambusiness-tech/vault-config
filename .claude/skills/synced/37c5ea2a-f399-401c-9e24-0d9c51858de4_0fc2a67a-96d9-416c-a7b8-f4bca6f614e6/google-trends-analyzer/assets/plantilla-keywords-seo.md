# Plantilla: Investigación de keywords SEO/SEM con Google Trends

Úsala para estructurar el spreadsheet (.xlsx) de keywords. Columnas sugeridas para la hoja principal:

| Columna | Descripción |
|---|---|
| Keyword / Topic | El término o tema |
| Tipo | Término literal / Topic |
| Categoría de intención | Informacional / Transaccional / Comparativa / De marca |
| Estado en Trends | Top / Rising / Breakout |
| Índice de interés actual (relativo) | 0-100, indicar sobre qué consulta/periodo |
| Mes(es) de mayor interés | Estacionalidad si existe |
| Tendencia 12 meses | Subiendo / Estable / Bajando |
| Tendencia 5 años | Subiendo / Estable / Bajando |
| Mercado(s) con mayor interés | País/región |
| Prioridad sugerida | Alta / Media / Baja |
| Notas | Contexto, causa de picos, riesgos (muestra pequeña, insufficient data, etc.) |

## Segunda hoja: resumen ejecutivo

- Top 5 keywords prioritarias y por qué
- Keywords en fase "rising, no top" (oportunidad antes de saturación)
- Calendario resumido: qué mes atacar cada grupo de keywords
- Advertencias: cualquier keyword con datos insuficientes o señal poco fiable

## Criterio de priorización sugerido

1. **Alta**: rising o breakout + intención transaccional/comparativa + sin señales de datos insuficientes.
2. **Media**: top estable con buena estacionalidad conocida (contenido "evergreen" con picos previsibles).
3. **Baja**: interés plano o decreciente, o datos insuficientes que no permiten confiar en la señal.

Recuerda al usuario en el propio archivo (celda de nota o pestaña de resumen) que el índice de Trends es interés relativo, no volumen de búsquedas — para volumen real recomendar cruzar con Keyword Planner/Ahrefs/Semrush antes de la decisión final de inversión en contenido.
