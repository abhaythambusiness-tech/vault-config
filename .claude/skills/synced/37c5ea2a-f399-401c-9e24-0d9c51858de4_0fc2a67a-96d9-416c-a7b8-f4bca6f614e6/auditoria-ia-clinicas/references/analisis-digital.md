# Framework de Análisis de Presencia Digital – Clínicas

## Cómo Investigar una Clínica en 15 Minutos

### 1. Google My Business
**URL:** `google.com/maps` → busca nombre clínica

Analiza:
- ⭐ Puntuación (< 4.2 es señal de problemas)
- 📝 Número de reseñas (< 50 = baja visibilidad)
- 💬 ¿Responden a reseñas negativas? ¿En cuánto tiempo?
- 📸 Fotos actualizadas o antiguas
- 🕐 Horario actualizado
- ❓ Preguntas y respuestas de usuarios

**Señales de dolor:**
- Reseñas que mencionan "no cogen el teléfono", "tardan en responder", "no contestan WhatsApp"
- Reseñas sin respuesta del propietario
- Puntuación baja sin respuesta a críticas

---

### 2. Instagram / Facebook
**Cómo analizar:**
- Busca el perfil directamente
- Para ver sus ads activos: `facebook.com/ads/library` → busca nombre de la página

Analiza:
- 📅 Frecuencia de publicación (posts/semana)
- 💬 ¿Responden comentarios? ¿En cuánto tiempo?
- 📣 ¿Tienen anuncios activos? ¿Qué creatividades usan?
- 🎯 ¿El CTA de los posts lleva a WhatsApp, web o formulario?
- 📊 Engagement rate estimado (me gustas / seguidores)

**Señales de dolor:**
- "Pide tu cita en el link de bio" → flujo friccionado
- Comentarios con preguntas de precio sin respuesta
- Anuncios con CTA a formulario web (fricción alta, conversión baja)
- Sin anuncios activos = solo tráfico orgánico, inestable

---

### 3. Web / Landing Page
Visita su web y evalúa:

| Elemento | Sí/No | Impacto |
|----------|-------|---------|
| ¿Botón de WhatsApp visible? | | Alto |
| ¿Formulario de contacto? | | Medio |
| ¿Reserva online? | | Alto |
| ¿Página de carga rápida? | | Medio |
| ¿Versión móvil correcta? | | Alto |
| ¿Precios visibles? | | Medio |
| ¿Testimonios/reseñas? | | Medio |
| ¿Chat en vivo/chatbot? | | Alto |
| ¿Pixel de Meta instalado? | | Alto |

**Herramientas gratuitas:**
- `pagespeed.web.dev` → velocidad de carga
- `builtwith.com` → tecnología que usan
- Facebook Pixel Helper (extensión Chrome) → tienen pixel instalado?

---

### 4. WhatsApp Business
Intenta escribirles por WhatsApp (si el número está en su web/redes):

Mide:
- ⏱️ Tiempo de respuesta (a qué hora escribes y cuándo responden)
- 🤖 ¿Tienen mensaje de bienvenida automático?
- 💬 ¿Responde persona o bot?
- 📋 ¿Tienen catálogo de servicios configurado?
- 🏷️ ¿Usan etiquetas para organizar conversaciones?

**Señales de dolor:**
- Responden fuera de horario laboral (o no responden)
- Sin mensaje de bienvenida
- Respuesta genérica sin cualificación
- Número de móvil personal (no WhatsApp Business)

---

### 5. Doctoralia / Top Doctors
Busca la clínica en `doctoralia.es`

Analiza:
- ¿Están dados de alta?
- ¿Tienen perfil completo o básico?
- ¿Puntuación y número de opiniones?
- ¿Tienen reserva online activada?
- ¿Aparecen en primeras posiciones para su especialidad en su ciudad?

---

### 6. Competencia Local
Busca `"clínica dental [ciudad]"` o `"fisioterapia [ciudad]"` en Google:

Identifica:
- ¿Cuántos competidores aparecen?
- ¿Quién está haciendo ads (aparece con etiqueta "Anuncio")?
- ¿Tienen mejor GMB que el prospect?
- ¿Qué ofrecen como gancho? (primera visita gratis, descuento, diagnóstico gratuito)

## Scorecard de Diagnóstico Digital

Usa esta puntuación para determinar el nivel de madurez:

| Área | 0 pts | 1 pt | 2 pts |
|------|-------|------|-------|
| GMB | Sin perfil o < 4.0 | 4.0-4.4, pocas reseñas | 4.5+, muchas reseñas, responden |
| Redes sociales | Inactivas | Activas pero sin ads | Activas con ads y engagement |
| Web | Sin web o básica | Web pero sin conversión | Web optimizada con CTA claros |
| WhatsApp | Sin WhatsApp Business | WA Business básico | WA con auto-respuesta |
| CRM/Gestión | Sin sistema | Software básico | CRM con pipeline |
| Ads | Sin publicidad | Ads ocasionales | Ads consistentes + landing |

**Puntuación total:**
- 0-4: Nivel 0 (Analógica) → Starter Pack
- 5-7: Nivel 1 (Digital Básica) → Stack Medio
- 8-10: Nivel 2 (Digital Activa) → Stack Completo
- 11-12: Nivel 3 (Semi-automatizada) → Integración + Optimización
