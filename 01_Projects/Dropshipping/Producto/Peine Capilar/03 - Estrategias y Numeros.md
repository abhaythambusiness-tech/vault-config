Aplica [[Pricing y Margenes]], [[Idea - Producto Ancla + Consumible]], [[Tienda de Un Producto vs Multiproducto]].

## Modelo común a las dos estrategias
Producto ancla (peine, el que se anuncia) + consumible (aceite, mismo nicho y avatar). Cambia **cómo se empaqueta la primera compra**.

## Diccionario mínimo
- **MC (margen de contribución):** lo que queda de una venta tras restar producto + envío + comisión de pago + colchón de devoluciones. Con eso pagas los anuncios y ganas.
- **CPA:** lo que cuesta en ads traer una venta.
- **Margen x4:** PVP = 4× coste de producto (regla del vault).

## Supuestos de cálculo

| Concepto | Valor |
|---|---|
| Coste producto — escenario Sheet (AliExpress) | peine 9,59 € · aceite 12,19 € |
| Coste producto — escenario realista (agente/UE) | peine 15 € · aceite 16 € |
| Envío al cliente | 3,50 € (1 producto) · 4,50 € (pack de 2) |
| Comisión pasarela | 2,9 % del PVP + 0,25 € |
| Colchón devoluciones/incidencias | 3 % del PVP |
| CPA objetivo | **22 €** (rango realista belleza/capilar 18–28 €) |
| % que marca el order bump | 30 % |

## Estrategia A — Peine solo (62,90 €) + order bump del aceite

**Cómo se ve:** anuncias solo el peine a 62,90 € → en el pago, casilla *"Añade el aceite (2 meses) por +24,90 €"* → tras pagar, upsell 1 clic *"2º frasco a mitad de precio"* → semanas después, suscripción de recarga.

### Números — situación **SIN order bump**

| Métrica | Coste Sheet | Coste realista |
|---|---|---|
| PVP | 62,90 € | 62,90 € |
| Múltiplo sobre coste del peine | **x6,6** ✅ | **x4,2** ✅ |
| MC antes de anuncios | **45,85 €** | **40,44 €** |
| Beneficio neto por venta (CPA 22 €) | 23,85 € | 18,44 € |
| CPA break-even | 45,85 € | 40,44 € |
| ROAS break-even | 1,37 | 1,56 |

### Números — situación **CON order bump** (+24,90 € del aceite)

| Métrica | Coste Sheet | Coste realista |
|---|---|---|
| Ingreso | 87,80 € | 87,80 € |
| Margen extra que deja el aceite | +10,99 € | +7,18 € |
| MC antes de anuncios | **56,84 €** | **47,62 €** |
| Beneficio neto por venta (CPA 22 €) | 34,84 € | 25,62 € |
| CPA break-even | 56,84 € | 47,62 € |

### Media real (30 % marca el bump)

| Métrica | Coste Sheet | Coste realista |
|---|---|---|
| MC medio antes de anuncios | **49,15 €** | **42,59 €** |
| AOV (ticket medio) | ~70 € | ~70 € |
| Beneficio neto medio (CPA 22 €) | ~27 € | ~20 € |

**A favor:** entrada barata → más ventas. Cumple x4 incluso con coste realista. **En contra:** si nadie marca el bump, el ticket se queda en 62,90 €.

## Estrategia B — Pack peine + aceite juntos (72 €) + recargas aparte

**Cómo se ve:** anuncias el pack a 72 € → order bump/upsell = 2º frasco de aceite a 19,90 € → semanas después, suscripción de recarga.

### Números

| Métrica | Coste Sheet | Coste realista |
|---|---|---|
| PVP del pack | 72,00 € | 72,00 € |
| Coste de producto del pack | 21,78 € | 31,00 € |
| Múltiplo sobre coste | **x3,3** ❌ | **x2,3** ❌ |
| (para x4, el pack debería costar) | 87 € | 124 € |
| MC antes de anuncios | **41,22 €** | **32,00 €** |
| — con bump 2º aceite (25 % lo marca) | 42,75 € | 32,58 € |
| Beneficio neto por venta (CPA 22 €) | ~20 € | ~10 € |
| CPA break-even | 41 € | 32 € |
| ROAS break-even | 1,75 | **2,25** |

**A favor:** ticket alto sin depender del bump; oferta "todo incluido" fácil; el cliente engancha antes con la recarga. **En contra:** **no cumple x4**; a coste realista te obliga a ROAS 2,25 solo para no perder ([[Pricing y Margenes]]: *si solo es rentable en el escenario optimista, el margen es demasiado ajustado*); 72 € en frío baja la CVR frente a 62,90 €.

## Comparativa

| | **A: Peine 62,90 + bump** | **B: Pack 72 + recargas** |
|---|---|---|
| Cumple margen x4 | ✅ (x6,6 / x4,2) | ❌ (x3,3 / x2,3) |
| Beneficio neto/venta (realista, CPA 22) | ~20 € | ~10 € |
| ROAS mínimo para no perder | 1,4–1,6 | 1,8–2,3 |
| Barrera de entrada | Baja | Media-alta |
| Riesgo | que no marquen el bump | margen fino + menos CVR en frío |
| Encaje con el playbook | Alto | Bajo (choca con principio #1) |

## Cuál usar
- **A = oferta principal** (tráfico frío). Respeta la regla de margen del vault y da entrada barata.
- **B = oferta secundaria:** test A/B de landing contra A, retargeting, o Black Friday con descuento. Nunca como única oferta a tráfico frío.
- En las dos, el dinero está en las **recargas** → [[08 - Retencion]].
