## KPIs — semáforo

| Métrica | Verde | Ámbar | Rojo |
|---|---|---|---|
| CTR del creativo | > 2 % | 1–2 % | < 1 % |
| CPC | < 0,30 € | 0,30–0,50 € | > 0,50 € |
| CVR de la tienda | > 2 % | 1–2 % | < 1 % |
| CPA (coste por venta) | < 22 € | 22–40 € | > 45 € |
| ROAS día 1 | > 2,0 | 1,4–2,0 | < 1,4 |
| % que marca el order bump | > 30 % | 15–30 % | < 15 % |
| Devoluciones | < 3 % | 3–6 % | > 6 % |

## Riesgos y validaciones pendientes
- [ ] **Legal (bloqueante):** copy sin ninguna promesa de recrecimiento → [[01 - Legal y Alegaciones]].
- [ ] **Coste real** de peine y aceite con agente/UE → recalcular [[03 - Estrategias y Numeros]].
- [ ] **Proveedor europeo del aceite** + **CE del peine** → [[04 - Proveedor y Envios]].
- [ ] **Demanda** confirmada en Trends + varios anunciantes en Ads Library > 2–3 semanas.
- [ ] **Margen propio del consumible** confirmado (que la recarga gane dinero sola).
- [ ] **Ciclo de consumo del frasco** (¿cuántas semanas dura?) para calibrar win-back y suscripción.
- [ ] **Precio final del peine:** 59,90 / 62,90 / 64,90 € (con coste realista, 62,90 es el mínimo cómodo).
- [ ] **Precio del order bump:** 24,90 € (más margen) vs 19,90 € (lo marca más gente).
- [ ] Decidir si se hace **test A/B** Estrategia A vs B con tráfico real.
- [ ] Minar **reseñas reales** para cerrar el avatar con frases textuales → [[02 - Avatar y Posicionamiento]].
