# Validación y testeo de producto

## La mala solución del testing en Meta — Video 4
Error común: 50€/día en Meta, 5 creativos, esperar 3 días, si no funciona reiniciar con producto nuevo cada semana → ~700€/mes, ~4.000€ en 6 meses quemados sin encontrar producto ganador.

**Alternativa recomendada para principiantes sin presupuesto: testing orgánico.**
- Crear página de Facebook, cuenta de Insta y cuenta de TikTok.
- Publicar **5 contenidos/día durante 20 días** (100 piezas de contenido).
- Diversificar formatos, hooks, visuales y ángulos de marketing.
- Objetivo: generar **3 ventas/día sostenidas durante 7 días seguidos** → demanda validada, momento de pasar a pago.
- Si falla, el problema no es el producto: es la falta de método de testeo.

## Arrancar con presupuesto — Video 5
Desglose de presupuesto realista para lanzar una marca (escenario pesimista):
| Fase | Coste estimado |
|---|---|
| Investigación de producto (métodos gratuitos: apps de Shopify, Amazon, orgánico) | 0€ |
| Análisis del producto (herramienta tipo TrendTrack) | ~50€/mes |
| Sourcing/proveedor (dropshipping = sin stock que prever) | ~500€ colchón de seguridad |
| Posicionamiento y diferenciación (grupos FB, reseñas Amazon, benchmarking) | 0€ |
| Branding | 0€ |
| Web (Shopify + herramienta tipo Cloud) | ~20€/mes + 1€ Shopify |
| Testeo orgánico del producto | 0€ |
| Publicidad de pago (ads) | 2.000-3.000€ |
| **Total recomendado** | **3.000€ – 5.000€** |

**Regla de validación orgánica:** si el contenido convierte visitas en ventas sin gastar en ads, el product-market fit está validado a coste cero antes de escalar con publicidad.
