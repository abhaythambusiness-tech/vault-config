# 01 - Tipos de producto (Micro SaaS, SaaS, Startup)

> [!resumen] En cristiano
> Tipos comunes de productos de software y sus características distintivas. Sirve como referencia al definir el tipo del proyecto en la ficha de inicio.

## Tipos de producto

| Tipo | Descripción | Casos de uso típicos |
|---|---|---|
| **Micro SaaS** | Producto SaaS estrecho, suele ser un solo caso de uso o funcionalidad específica. | Herramientas especializadas, complementos, utilidades específicas |
| **SaaS** | Plataforma de software como servicio con múltiples funcionalidades, módulos o integraciones. | Sistemas de gestión, plataformas de e-learning, herramientas de productividad |
| **Startup** | Empresa en fase temprana que busca validación de mercado y crecimiento rápido. | Mercado nuevo, producto innovador, búsqueda de ajuste producto-mercado |

## Cómo definir el tipo de tu proyecto

1. **¿Resuelve un problema específico y estrecho?** → Micro SaaS
2. **¿Tiene múltiples funcionalidades para diferentes usuarios?** → SaaS
3. **¿Estás buscando validación de mercado y crecimiento rápido?** → Startup

*Nota: La mayoría de los proyectos empiezan como Micro SaaS y evolucionan hacia SaaS a medida que crecen las funcionalidades y la base de usuarios.*
