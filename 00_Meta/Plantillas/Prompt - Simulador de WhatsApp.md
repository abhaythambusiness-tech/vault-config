# Prompt - Simulador de WhatsApp

> [!resumen] En cristiano
> Prompt para simular conversaciones por WhatsApp, útil para testing de flujos, diseño de experiencia o capacitación de equipos.

## Estructura del prompt

```
### Contexto
{Contexto de la simulación: qué escenario se representa y para qué propósito}

### Personaje
{Nombre del asistente/agente: rol y personalidad}

### Objetivo
{Qué se busca lograr con la simulación: capacitación, testing, diseño, etc.}

### Escenario
{Descripción del escenario: situación inicial, partes involucradas, resultado esperado}

### Restricciones
-{Limitaciones o reglas del simulación}

### Formato de salida
{Cómo debe presentarse el resultado: texto, tabla, estructura específica}
```

## Casos de uso

- **Testing de flujos**: Validar que el mensaje correcto se envía en cada situación.
- **Diseño de experiencia**: Probar diferentes enfoques de comunicación antes de implementar.
- **Capacitación**: Entrenar al equipo en la respuesta a diferentes tipos de consultas.
